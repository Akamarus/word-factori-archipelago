# Tester feedback investigation — 2026-09-16

This is unreleased local verification, not a live-playthrough or release claim.
The installed game, player saves and public GitHub release were not changed.
Native probes use a separate scratch game copy and isolated save namespace.
Raw game source, binaries, recipes and fonts are not included in this report.

## Source generation

The packaged APWorld generated successfully with Archipelago 0.6.7 both from
its source directory and from an unrelated working directory. Current 0.6.8
source at commit `e0b6083384cd37019f4c41da0970dff1d99f1325` rejected the old
`maximum_ap_version: 0.6.7` metadata and subsequently reported no functional
Word Factori world. After raising the ceiling to 0.6.8, generation succeeded
from the unrelated directory. No path-dependent import failure was reproduced.
The reporter supplied no traceback, so this is a reproduced compatibility
failure, not proof it was the exact failure on their machine.

The fixtures use the actual packaged `.apworld`, not a loose source import.
The two-player test combines 40 factories, 187 recipes and three word orders
in progressive mode with 30 factories and three orders in normal mode:
263 checks total, with full accessibility and completed spoiler generation.
The selected-target spoiler section identifies the player and each Word Order
check. Seeds used: 160926/160927 (0.6.7), 160928 (0.6.8 single-player), and
160929 (0.6.8 two-player), and 160930 (0.6.7 two-player, also successful).
Dependencies are isolated test dependencies.
This does not establish full 0.6.8 client/Universal Tracker compatibility.

Existing quantity rules were checked before changing them. An isolated native
probe then built the catalog's complete factory witnesses using real native

Each successful factory manufactured ten target letters and completed natively.

Useful construction hints: the S witness rotates I, bends it into U, rotates U,
merges that with I and rotated I into 5, then bends 5. The B witness starts with
four I inputs merged to W, rotates W, bends it to 3, then merges 3 with I.
The H witness rotates I and merges three I inputs plus that rotated I into 4,
then merges 4 with I. Reuse/fan-out of a producer is permitted; the budgets
count placed machines, not how many times their output is consumed.

Regression tests exercise both original world rules and tracker-restored rules
at the exact reported inventories. Page gates are tested separately. No change
was made to the recipe catalog based solely on the unconfirmed discrepancies.
The reported `(`, `(2`, `2`, `#` and `4` outputs are symbols, not among the 187
letter-output Recipe Journal locations. Their production routes are available
to Type-a-Word logic; adding symbol-recipe checks is a separate feature.

## Progressive simulation overhead

The old production guards counted the full scene repeatedly from individual
building operations. This made scan work grow with both scene size and the
number of machine callbacks. A memory leak was not demonstrated.

The scoped fix validates the full scene and simulation graph at tick entry,
captures known-machine permissions, then reuses them only during the existing
synchronous native tick. The native method body is preserved. Normal return,
early return and exceptions clear the snapshot; errors are rethrown. Custom
factories and locked families remain denied even inside that scope. UI previews,
placement, item polling and win checks do not reuse a previous tick's snapshot.

Same isolated native scenario, one measured tick at each size:

| Scene modules | Before: full scene scans | After: full scene scans | Before / after elapsed |
|---:|---:|---:|---:|
| 16 | 25 | 1 | 80.3 / 8.5 ms |
| 64 | 85 | 1 | 271.6 / 10.5 ms |
| 128 | 137 | 1 | 452.4 / 10.9 ms |

The old implementation fails the new one-scan assertions; the candidate passes
all 99 isolated native enforcement/quantity assertions. Tests cover actual
production, early returns, error cleanup, an excess placement between ticks,
a reduced allowance, a later live upgrade and blocked buffered completion.
Timings are single-run diagnostics, not an FPS guarantee or a sustained-memory
benchmark. Scene scans and graph checks outside the tick remain deliberate.

The production patch was compiled and reopened across all nine checked hook
entries. Its delta was independently reapplied to the verified original and
matched the candidate byte-for-byte. Candidate SHA-256:
`6f05e35357faa53cfb7f3314501e7edd295245c05d705294bf972a801fe1356b`.
Windows and Linux installer fixtures cover upgrade from 1.5.1 and restore.

## AP Mail target list

The new read-only Type-a-Word tab uses the authoritative room contract, not
local YAML or a resampled list. Status comes from pending check reconciliation
and server acknowledgments. Rendering does not read saves or repeatedly rebuild
the quantity campaign. Cached presentation data is invalidated when room data
changes. Disconnected/disabled/incompatible states have explicit messages.

Protocol, lifecycle and spoiler tests cover target bounds, immutable snapshots,
room switches, reconnects, pending/confirmed checks and regular-client discovery.
The actual Kivy widgets were rendered and inspected using the locally installed
game font, including long symbol targets and completion states. No font asset
is redistributed. Connected native-window clicks and a complete Linux/Proton
playthrough remain manual acceptance work.

## Scope not included

Recipe filler percentage, a default-max-speed preference, real sticker awards,
symbol-recipe locations and a broader naming/logging pass are deferred. None
of those changes is required to validate the scoped fixes above.
