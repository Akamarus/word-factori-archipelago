# Word Factori Archipelago 1.2.0 — Experimental Public Beta

This experimental public beta delivers the full 30/40-level Word Factori Archipelago experience.

## Highlights

- Selectable 30-level Core Campaign or recommended 40-level Discovery Labs.
- Machine and Progressive World Access item logic with deterministic recipe reachability.
- Idempotent save-slot binding, item/check reconciliation, reconnect handling, and victory.
- Integrated Word Factori-styled Items/Chat client with left-side notifications.
- Digest-verified custom campaigns and a Windows installer.
- Verified against Archipelago 0.6.7 and Word Factori Steam build 12616577.

## Install

1. Download `word-factori-archipelago-hybrid-1.2.0.zip`.
2. Extract it to a normal folder.
3. Close Word Factori and Archipelago.
4. Double-click **Install Word Factori Archipelago.cmd**.

See the included README for setup and first-game instructions. Windowed and borderless modes are supported. Exclusive fullscreen falls back to the regular client.

This remains experimental while password-room and broader display/hardware testing continue.
