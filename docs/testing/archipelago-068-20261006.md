# Archipelago 0.6.8 compatibility — 2026-10-06

## Scope and artifact

The existing **v1.7.0 tester prerelease** was tested against the final official
Archipelago 0.6.8 source tag, commit
`54803be064fc7e80c4628777ed0b46a9390f255f`.
This supersedes the earlier development-source generation-only evidence.

Published APWorld SHA-256:
`fc75e5b417e574f2e08ab17d830c258916ed3f1bab2ec4599213f482b037d2a9`.
The two generation matrices and recorded connected runs below used that exact
package, frozen before execution. GitHub's release asset digest matched it.
No gameplay code, native patch, item/check IDs, room contract, YAML option or
default needed changing. Published v1.7.0 assets and tag remain unchanged.
Source documentation updates change a locally rebuilt package's bytes, not its
runtime code; they are not replacements for the published assets.

## Results

- **809 repository tests:** passed with eight explicitly skipped opt-in/platform
  cases; the real-AP cases were exercised separately below.
- **74/74 actual Universal Tracker cases:** saved-room reconstruction and exact
  in-logic sphere comparisons, including normal/progressive modes, both bundled
  campaigns, optional recipe/word checks, goals and start inventory.
- **74/74 mixed Kingdom Hearts cases:** generation, beatability, configured
  accessibility and saved-slot reconstruction; no failures or timeouts.
- **17 real-AP acceptance/regression tests:** all passed, including both shipped
  example YAMLs and deliberate premature-victory/inaccessible-check rejection.
- **13 corresponding connected/CI/example tests against 0.6.7:** all passed.

Two independent 0.6.8 connected rooms (seeds 160929 and 160930) each completed
**263/263 checks and 2/2 server-confirmed goals**. Both verified cross-player
delivery, client restart after offline completion, same-instance reconnect,
duplicate checks, full item replay, page gating and tracker reconstruction.

The APTests matrices used Universal Tracker 0.2.26 from the previously tested
bundle and the same Kingdom Hearts companion as the September regression pass.
They do not establish compatibility with every future version of those worlds.
The new Windows/Ubuntu CI matrix pins both final AP versions and runs connected
rooms plus packaged generation regressions. Consult the linked commit's CI
results for platform-specific evidence.

## Reproduce

Use Python 3.12 and install `tools/requirements-connected.txt` in an isolated
environment. Obtain official AP source at the pinned commit. Use a trusted
v1.7.0 APWorld download, and supply NEW output folders for each command.

```text
python tools/verify_connected_multiworld.py --ap-source AP_SOURCE --apworld RELEASE_APWORLD --seed 160929 --output NEW_FOLDER
python tools/verify_connected_multiworld.py --ap-source AP_SOURCE --apworld RELEASE_APWORLD --seed 160930 --output ANOTHER_NEW_FOLDER
python tools/verify_aptests_regressions.py --ap-source AP_SOURCE --apworld RELEASE_APWORLD --tracker TRUSTED_TRACKER_APWORLD --extra-seeds 40 --output NEW_TRACKER_FOLDER
python tools/verify_aptests_regressions.py --ap-source AP_SOURCE --apworld RELEASE_APWORLD --kingdom-hearts TRUSTED_KH_APWORLD --extra-seeds 40 --output NEW_MIXED_FOLDER
```

Set `WF_AP_SOURCE` to opt into real-AP unit tests; also set `WF_KH_APWORLD` for
the mixed-game regression. Ordinary `python -m unittest discover -s tests -q`
runs the repository suite; opt-in/platform skips must not be counted as live
acceptance. Generation workers run outside the AP source folder.

The first attempts exposed test-runner assumptions, not runtime failures:
the runner admitted only 0.6.7 and omitted 0.6.8's new `apmw` core package.
Both were corrected with regression coverage. The headless dependency pin was
aligned with 0.6.8's `platformdirs==4.10.1`.

## Player guidance and limits

Use the existing v1.7.0 download with AP 0.6.8. Merely upgrading AP does not
require a new Word Factori room/save, a changed YAML, or a new native patch.
If AP is installed to a different folder, install the same APWorld there.
Normal fresh-room guidance still applies when starting a new playthrough or
upgrading from an older Word Factori integration.

The game boundary is simulated in connected tests. This does **not** prove
native puzzle solving, GUI launch, in-game AP Mail input/rendering, Proton
behavior or sustained performance under 0.6.8. It is not a stable-release
promotion. No installed game or real save was modified by these checks.
