# Word Factori Experimental Multiworld Setup

Extract the release, close Word Factori and Archipelago, and double-click **Install Word Factori Archipelago.cmd**. Restart both programs, then select **word factori archipelago** with an empty game save slot. A room uses either the 30-level Core Campaign or the 40-level set containing those canonical campaign checks plus ten Discovery Labs.

For an update, run `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Force`. To remove only this integration's APWorld and mod folder, run the same command with `-Uninstall`.

Use the 1.3.0 APWorld and client to generate a new room. Choose `custom_level_set: core_campaign` for 30 custom levels or `custom_level_set: discovery_labs` for the recommended 40-level set. The default `campaign_layout: shuffled_pages` builds deterministic seed-specific six-level pages; choose `fixed_pages` to keep the canonical bundled order. Existing 1.2.x rooms retain the canonical order and server logic with which they were generated and remain supported by the 1.3.0 client.

Finish the first page in native order: **I → C → V → L → O → A**. All six tutorial checks are required to open page two. The later pages have seed-specific membership and order; every level on an unlocked later page is independently selectable. Complete any four of its six levels to open the next page, and return for the other two whenever you want. The world requests local-early Merger2 Access and Rotation Access so the tutorial's required machinery is not placed behind itself. Later pages retain machine-profile diversity but may be Merger2-heavy; at most one later Core Campaign page can have four Rotation-dependent checks.

Rooms from the earlier unpublished 1.3.0 beta that shuffled the tutorial must be regenerated with this APWorld and started in an empty mod save. The client rejects those invalid beta contracts. Updating the client alone cannot change their server rules.

Launch **Word Factori Client**, then connect from the in-game panel, the regular client, or an `archipelago://` link. The game save records native slots, while the client maps them back to stable canonical AP location IDs even when the shuffled layout moves a level. Received machine items and Progressive World Access copies update only this mod's supported `levels.json` and `archipelago_campaign.json`; return to save select or restart Word Factori after new unlocks. Sticker deliveries and ordinary reconnects do not require a reload.

The client reads completed level indices but never writes the Word Factori save. It binds each room to one empty save slot and refuses checks if existing progress is present or the active slot changes. It also refuses checks and mod regeneration if the connected room and installed campaign identities differ.

Received items appear as blue popups on the left side of Word Factori. Click **AP MAIL** or press **F8** for the integrated **Items** and **Chat** panel. It supports manual connection, disconnect, connection status, chat, hints, commands, and masked password entry. Enter sends text, Shift+Enter inserts a line, and Escape closes the panel and returns focus to the game. The display works in windowed and borderless modes; use the regular Word Factori Client in exclusive fullscreen. If it does not appear, use `/wf_overlay status` and `/wf_overlay restart`. The overlay is optional, so item delivery and check reporting continue if its renderer stops.

Version 1.3.0 is an experimental beta candidate with live acceptance pending. Automated coverage exercises the sequential tutorial, six-then-four gates, shuffled later pages and save selection. Only the bundled digest-verified `core_campaign` and `discovery_labs` manifests can be selected; arbitrary Workshop packs are not imported. An optional enhanced binary-patch prototype is in development, but is not enabled or included in this player build; the reload instructions above still apply.
