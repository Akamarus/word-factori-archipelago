# Word Factori Experimental Multiworld Setup

Extract the release, close Word Factori and Archipelago, and double-click **Install Word Factori Archipelago.cmd**. Restart both programs, then select **word factori archipelago** with an empty game save slot. A room uses either the 30-level Core Campaign or the 40-level set containing those canonical campaign checks plus ten Discovery Labs.

For an update, run `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Force`. To remove only this integration's APWorld and mod folder, run the same command with `-Uninstall`.

Use the 1.4.0 APWorld and client to generate a new machine-only room. Choose `custom_level_set: core_campaign` for 30 levels or `discovery_labs` for 40. New rooms have no World Access items and always allow I. Machines, recipe requirements, and page progress determine reachability. Labs keep their declared machine restrictions. Existing valid 1.2.x/1.3.x rooms retain their original layout and tier locks; use a new room and empty save to change progression.

In supported mode, finish the first page in native order: **I → C → V → L → O → A**. All six tutorial checks are required to open page two. The later pages have seed-specific membership and order; every level on an unlocked later page is independently selectable. Complete any four of its six levels to open the next page, and return for the other two whenever you want. The world requests local-early Merger2 Access and Rotation Access so the tutorial's required machinery is not placed behind itself. Later pages retain machine-profile diversity but may be Merger2-heavy; at most one later Core Campaign page can have four Rotation-dependent checks.

Rooms from the earlier unpublished 1.3.0 beta that shuffled the tutorial must be regenerated with this APWorld and started in an empty mod save. The client rejects those invalid beta contracts. Updating the client alone cannot change their server rules.

Launch **Word Factori Client**, then connect from the in-game panel, regular client, or an `archipelago://` link. Native save slots map to stable AP location IDs. In supported mode, return to save select or restart Word Factori after machine unlocks. The separate enhanced playtest refreshes machines on factory entry: return to Levels and re-enter, without restarting the game. Stickers and ordinary reconnects do not require a reload. World Access updates apply only to old rooms.

The client reads completed level indices but never writes the Word Factori save. It binds each room to one empty save slot and refuses checks if existing progress is present or the active slot changes. It also refuses checks and mod regeneration if the connected room and installed campaign identities differ.

Received items appear as blue popups on the left side of Word Factori. Click **AP MAIL** or press **F8** for the integrated **Items** and **Chat** panel. It supports manual connection, disconnect, connection status, chat, hints, commands, and masked password entry. Enter sends text, Shift+Enter inserts a line, and Escape closes the panel and returns focus to the game. The display works in windowed and borderless modes; use the regular Word Factori Client in exclusive fullscreen. If it does not appear, use `/wf_overlay status` and `/wf_overlay restart`. The overlay is optional, so item delivery and check reporting continue if its renderer stops.

Version 1.4.0 is a local development candidate with live acceptance pending. Only the bundled digest-verified `core_campaign` and `discovery_labs` manifests are selectable; arbitrary Workshop packs are not imported. The standard package does not patch the game. The separate opt-in enhanced playtest requires its exact-build patch and a new enhanced room, randomizes the first page, and opens page two after four completions. An in-game missing-machine notice remains planned.
